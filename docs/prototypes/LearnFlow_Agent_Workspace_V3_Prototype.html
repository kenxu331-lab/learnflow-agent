核心区别：Depends() 是向 FastAPI 声明依赖关系；普通函数调用则由你自己决定何时调用。

  • 依赖解析：FastAPI 根据声明解析依赖及其子依赖。
  • 调用时机：框架在处理请求时负责求值并处理所需参数。
  • 结果注入：依赖函数的结果提供给对应路径操作参数。
from typing import Annotated
from fastapi import Depends, FastAPI

app = FastAPI()

def common(q: str | None = None):
    return {"q": q}

@app.get("/items")
def items(params: Annotated[dict, Depends(common)]):
    return params

因此更准确的理解是：你声明依赖，框架负责执行依赖解析。两者并不完全等同。
